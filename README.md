# ChispasIA

Web estatica para GitHub Pages de un chatbot de IA llamado **ChispasIA**.

Lema: **Tu chispa de inteligencia**.

## Archivos

- `index.html`: estructura principal de la web.
- `styles.css`: diseno responsive.
- `script.js`: demo de chat, registro, inicio de sesion y generador visual.
- `assets/chispasia-hero.svg`: imagen creada para la portada.

## Publicar en GitHub Pages

1. Crea un repositorio en GitHub.
2. Sube todos los archivos de esta carpeta.
3. Entra en `Settings > Pages`.
4. En `Branch`, elige `main` y carpeta `/root`.
5. Guarda y abre la URL que GitHub te genere.

## Nota importante

El registro e inicio de sesion funcionan como demo local usando `localStorage`.
Para cuentas reales necesitas conectar un backend como Firebase, Supabase o una API propia.
